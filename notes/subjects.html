五科要点

考核构成与内容范围

下面每科给出两部分：分数怎么构成，以及每项考核覆盖哪些内容。

MAM · 数学方法

权重构成：Tests 34% + Investigation 26% + Examination 40% = 100%

考核内容范围
Topic Tests 1–3进阶微分与应用：指数与三角函数的求导法则、二阶导数及其应用
Investigation制定方案、研究、实施并汇报；课堂内验证
Final ExaminationUnit 3 与 Unit 4 全部内容：积分、对数函数、离散与连续随机变量、正态分布、比例的区间估计

注意 Topic Test 2 单项占 20%——比两次 Investigation 中的任何一次都重，而且落在 11 月考试周内。

PHY · 物理

权重构成：Tests 40% + Examination 50% + Science Inquiry 10% = 100%

考核内容范围
Topic Test 1 / 2截至该阶段所学的单元内容，以题目与计算形式考查
Evaluation & Analysis对物理情境做延伸性的评估与分析
Lab Assessment科学探究：实操加笔试两部分
Evaluation Exam / Final Evaluation累积性考试；期末覆盖 Unit 3 与 Unit 4 全部

注意 Topic Test 两项合计 28%，只比期末的 30% 少一点。只盯期末会把将近三成的分数放掉。这一科的大纲未给出具体日期。

CSC · 计算机

权重构成：Project 40% + Examination 40% + Theory test 10% + Practical Test 10% = 100%

考核内容范围
Task 1 (Project)为客户编写面向对象程序：二维数组、类、控制结构；含设计开发、评估、项目验证
Task 2 (Practical Test)在电脑上完成的一组难度递增的编程题
Task 4 (Theory Test)网络通信与网络安全：CISCO 规范的网络图、编址、子网、分段与安全
Task 5 (Project)集成数据库编程方案：关系数据库设计与 SQL 查询，含参照完整性、增删、内连接、计算字段
Task 3 / Task 6 (Examination)各 3 小时笔试，依据 ATAR Year 12 考试设计概要

两个 Project 合计 40%，与两次考试总分相等，而且都跨数周——最需要提前动手。

ELD · 英语

权重构成：Written production 30% + Oral production 10% + Response 15% + Investigation 15% + Final examination 30% = 100%

考核内容范围
Task 1 / Task 6书面产出：论述文与说服性演讲，现场命题
Task 2A / 2B调查研究：先做口头研究提案，再提交书面研究报告
Task 3 (COAT)由 SCSA 统一命题、学校组织的口语统考
Task 4 / Task 5应答：听力理解，以及阅读理解配综合写作
Task 7口语产出：面向同伴的说服性演讲
Task 8期末笔试

共 8 项任务，是五科中最多的一科；口语类任务合计超过 20%。建议录音自听——多数人察觉不到自己语速过快或停顿过多。

HBY · 人类生物

没有找到这一科可核实的考核数据，因此本页不列出权重与范围——宁可留空，也不填猜测的数字。

复习时优先看「内容范围」那一列——它直接告诉你每项考核会考到哪些主题，比笼统地把课本过一遍省时间。
