这个站是怎么做的

纯静态站点，没有框架、没有构建步骤——就是 HTML + CSS。

  • 公式由 KaTeX 渲染，字体和脚本都在本站 vendor/ 里，不依赖任何外部 CDN，断网也能正常显示
  • 配色跟随系统深色模式，手机上自适应
  • 按 Ctrl+P 可以直接打印成 PDF 交作业（打印时会自动去掉导航栏）

这就是第 2 课的实物。你现在看到的每个元素——卡片、提示框、表格、深色模式——都对应 CSS 里的一小段规则，改一个变量就能换整站配色。
